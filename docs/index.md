# Applied Robotics (12224)

## Course description

Manipulator and mobile robot kinematics, dynamics, feedback control, trajectory planning, perception, localization, SLAM, and autonomous navigation. Algorithm implementation in Python and NumPy, integration with ROS 2, and experimental validation in simulation and on physical robots.
