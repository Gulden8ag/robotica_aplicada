# Applied Robotics (12224)

Robótica Aplicada connects mathematical models, algorithms, simulation, and physical robot experiments. You will study how robots move, how they are controlled, how they perceive their surroundings, and how to measure whether a complete system works reliably.

Start with the [syllabus](Course_Overview/T0_1.md), then use the [31-session schedule](Course_Overview/schedule.md) to follow the course.

## How you will work

For each engineering problem, follow this progression:

**Model → Predict → Implement → Measure → Compare → Explain**

Develop the robotics algorithms first in Python and NumPy. Use ROS 2 to connect them with simulations, sensors, and robot interfaces. Installation and extended software configuration belong in preparation and reference material; class time focuses on the engineering principles and experimental results.

The course has **31 sessions of two hours**, totaling **62 contact hours**, with approximately **62 additional hours of independent project development**. Two projects run in parallel with instruction: a three-DOF manipulator and an autonomous mobile robot with Ackermann or Mecanum configuration.
