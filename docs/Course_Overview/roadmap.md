# Project roadmap

Two engineering projects contribute **30% each to the final course grade**. Development takes place outside class. Milestones are advisory; mandatory assessed checks are specified in the project requirements.

## Project 1 — Three-DOF robotic manipulator

A student-built, three-DOF robotic arm with an actuated mechanical structure, joint position feedback, and a programmed control interface. The arm must support joint commands, Cartesian positioning, and trajectory execution, with recorded position and tracking errors.

| Session | Development milestone | Relevant classroom content |
|---:|---|---|
| 4 | Project released; form teams, select a design, review requirements | Forward kinematics and DH |
| 7 | Mechanical design and kinematic model ready | Frames, FK, IK, Jacobians, robot models |
| 10 | Actuators operational, valid joint feedback, basic positioning | Dynamics and feedback control |
| 13 | Joint control and inverse kinematics functioning | Controller constraints and validation |
| 16 | Trajectory generation, execution, and experimental evidence | Joint-space and Cartesian trajectories |
| 17 | Final demonstration, team presentation, and individual technical defense | Project 1 evaluation |

## Project 2 — Autonomous mobile robot

A student-built mobile robot with an Ackermann steering mechanism or a Mecanum drivetrain, onboard sensing, odometry, and autonomous navigation software. The robot must estimate its motion, follow paths, and navigate around obstacles without manual control. Both configurations are evaluated under equivalent conditions.

| Session | Development milestone | Relevant classroom content |
|---:|---|---|
| 18 | Project released; system architecture and hardware plan | Mobile kinematics |
| 21 | Chassis, propulsion, and steering/wheel control operational | Odometry, path following, simulation |
| 24 | Odometry, path following, and initial sensor acquisition | Navigation architecture, vision, RGB-D |
| 27 | Autonomous behavior and navigation integrated | LiDAR, SLAM, perception, interfaces |
| 29 | System validation and performance measurements | Integration, repeatability, analysis |
| 30 | Reliability checks and submission readiness | Fault handling, safety, verification |
| 31 | Final demonstration, team presentation, and individual technical defense | Project 2 evaluation |
