# Parallel project roadmap

Two engineering projects connect the classroom topics with design, implementation, and experimental validation. Each contributes **30% of the final course grade**. Develop them primarily outside class, with approximately 62 independent-work hours across the course.

The milestones below are **advisory planning checkpoints**, not separate graded assignments. Arrange a meeting with the instructor when you need to discuss progress or a technical obstacle. Any mandatory assessed progress check must be identified explicitly when the project is assigned.

## Project 1 — Three-DOF robotic manipulator

Design, construct, and program a three-DOF manipulator for joint motion, Cartesian positioning, and trajectory execution. Accuracy, repeatability, feedback, and controlled motion are central to the challenge.

| Session | Development milestone | Relevant classroom content |
|---:|---|---|
| 4 | Project released; form teams, select a design, review requirements | Forward kinematics and DH |
| 7 | Mechanical design and kinematic model ready | Frames, FK, IK, Jacobians, robot models |
| 10 | Actuators operational, valid joint feedback, basic positioning | Dynamics and feedback control |
| 13 | Joint control and inverse kinematics functioning | Controller constraints and validation |
| 16 | Trajectory generation, execution, and experimental evidence | Joint-space and Cartesian trajectories |
| 17 | Final demonstration, team presentation, and individual technical defense | Project 1 evaluation |

## Project 2 — Autonomous mobile robot

Develop an autonomous vehicle using **Ackermann steering or Mecanum wheels**. The system combines controlled motion, odometry, path following, sensing, and autonomous navigation. Evaluation conditions must be technically equivalent for both configurations.

| Session | Development milestone | Relevant classroom content |
|---:|---|---|
| 18 | Project released; system architecture and hardware plan | Mobile kinematics |
| 21 | Chassis, propulsion, and steering/wheel control operational | Odometry, path following, simulation |
| 24 | Odometry, path following, and initial sensor acquisition | Navigation architecture, vision, RGB-D |
| 27 | Autonomous behavior and navigation integrated | LiDAR, SLAM, perception, interfaces |
| 29 | System validation and performance measurements | Integration, repeatability, analysis |
| 30 | Reliability checks and submission readiness | Fault handling, safety, verification |
| 31 | Final demonstration, team presentation, and individual technical defense | Project 2 evaluation |

## Specifications and assessment

This roadmap supports workload planning. Complete project specifications must be released at sessions 4 and 18 respectively, including cumulative performance tiers, deliverables, individual defense criteria, evaluation-day rules, and validated numerical requirements.

The detailed specifications are pending a separate review. Workspace targets, accuracy tolerances, motion limits, the mobile challenge layout, and its target time have not been set here. Use the complete specification issued by the instructor when preparing an assessed demonstration.

Project construction does not replace the instructional sessions. Sessions 17 and 31 are reserved for evaluation; sessions 27–30 teach integration and validation principles.
