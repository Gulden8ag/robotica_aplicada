# Resources and preparation

Use the [session schedule](schedule.md) to identify the current topic. The instructor specifies which readings and exercises are required. Extended setup and package-building tutorials remain available for reference.

## Before session 1

Review the prerequisites in the [syllabus](T0_1.md). Be ready to work with vectors and matrices, basic derivatives and integrals, Python functions, and NumPy arrays. Bring questions about prerequisites to the instructor early.

## Before session 2

Use the existing [installation and configuration guide](../M0_Fundamentals_and_Tools/T0_8.md) to prepare Ubuntu 24.04, ROS 2 Jazzy, VS Code, and the course visualization/simulation tools. Windows users use WSL2; native Ubuntu users follow the corresponding steps in the guide.

Check readiness before class:

- Open your Ubuntu terminal and source the ROS 2 environment.
- Verify that `ros2` is available and that the talker/listener example exchanges messages.
- Verify that a graphical ROS tool opens in your environment.
- Run a small Python calculation using NumPy.
- Check that you can open your code in VS Code and use Git.

If a check fails, record the command, the error, and your operating environment so the instructor can help diagnose it. The existing setup tutorial is awaiting its own technical review; report instructions that fail rather than spending the entire session repeatedly rebuilding the environment.

## Physical laboratory preparation

Use the laboratory's working manufacturer environment and approved robot interface. Ask the instructor for the station's operating procedure and verified limits before running physical motion. The UR5e requires supervision or validated training for independent use. Planned Dynamixel manipulators are optional until completed.
