# Lab Log

Record assigned activities, notes, and homework on your public Lab Log website. Submit the specific entry URL through Microsoft Teams. Assessment policies are listed in the [syllabus](T0_1.md).

## Entry template

**Title:** Session number and activity name.

**Identification:** Date, name/ID, team, and repository link.

Include only the sections relevant to the activity. Omit unused sections.

### 1. Objectives

**Use when:** Every entry.

State the calculations, algorithms, or functions to implement and validate.

### 2. Equipment and setup

**Use when:** Hardware, software configuration, or operating limits affect reproducibility. For computational work, list only the software and parameters used.

Record hardware, software versions, parameters, wiring, and operating limits needed to reproduce the experiment.

| Item | Quantity | Source | Cost (MXN) | Notes |
|---|---:|---|---:|---|
| | | | | |

### 3. Procedure

**Use when:** You performed an experiment, implementation, or configuration. Omit for entries limited to derivations or design discussion.

List the experimental steps, commands, and verification checks.

### 4. Data and tests

**Use when:** You ran tests or collected measurements. Omit if no tests were performed.

Record test inputs, expected results, measurements, and error metrics. Link raw data and plots.

| Case | Input | Expected result | Measured result | Error | Pass/Fail |
|---|---|---|---|---|---|
| | | | | | |

### 5. Analysis

**Use when:** You interpret calculations, results, or design decisions. For design work, state assumptions and tradeoffs instead of measurement comparisons.

Compare predictions and measurements. Explain discrepancies using the mathematical model and experimental conditions. Identify limitations and required corrections.

### 6. Code

**Use when:** Code was written, modified, or used to obtain results. Omit if the activity involved no code.

Link source files and the tested commit. Include short snippets only when needed to explain the implementation.

### 7. Files and media

**Use when:** Supporting artifacts are needed to reproduce or verify the work. Omit if none apply.

Link relevant CAD, URDF, launch files, firmware, measurement files, and videos.
