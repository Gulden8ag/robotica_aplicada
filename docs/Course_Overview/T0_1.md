# Syllabus

Study the engineering principles of robot motion, control, perception, and experimental validation. Implement algorithms in Python and NumPy, then use ROS 2 to connect them with simulation and physical robots.

[Session schedule](schedule.md) | [Project roadmap](roadmap.md) | [Lab Log guide](T0_2.md) | [Resources and preparation](T0_3.md)

## Course format and workload

The course consists of **31 sessions of two hours (62 contact hours)** and approximately **62 additional hours of independent project development**.

The regular meeting pattern is Tuesday and Thursday, 15:00-17:00. Confirm semester dates, holidays, assignment deadlines, and evaluation schedules in Microsoft Teams. The reusable [session schedule](schedule.md) defines the learning sequence without carrying forward dates from a previous semester.

Project 1 is assigned in session 4 and evaluated in session 17. Project 2 is assigned in session 18 and evaluated in session 31. All teams are evaluated on the same date for each project; the evaluation period may extend beyond two hours to accommodate all teams.

## Learning outcomes

By the end of the course, students should be able to:

- Represent coordinate frames and compute rotations and homogeneous transformations.
- Develop manipulator forward/inverse kinematics and analyze Jacobians and singularities.
- Derive a manageable dynamic model and evaluate feedback and model-based control.
- Generate joint-space and Cartesian trajectories subject to motion constraints.
- Apply differential-drive, Ackermann, and Mecanum kinematics, odometry, and path-following control.
- Process camera, RGB-D, and LiDAR data for perception, localization, mapping, and navigation.
- Integrate robotic subsystems and quantify accuracy, tracking error, repeatability, and reliability.
- Explain mathematical assumptions, algorithm implementations, experimental results, and engineering decisions.

Use **Model -> Predict -> Implement -> Measure -> Compare -> Explain** when approaching computational exercises and physical experiments. ROS 2 provides implementation and integration tools throughout this process.

## Prerequisites

- **Math:** single & multivariable calculus; linear algebra (vectors, matrix ops, rank/nullspace, Jacobian, SVD/conditioning); basic ODEs (1st/2nd order).
- **Mechanics:** rigid-body kinematics; statics/dynamics (Newton–Euler or work–energy) at an undergraduate level.
- **Control basics:** LTI step response specs (rise/settling/overshoot), PD/PID fundamentals, discrete-time sampling, saturation & anti-windup conceptually.
- **Programming:** Python (NumPy, basic plotting), Git fundamentals (clone/commit/branch/merge), Linux shell (WSL2 terminal navigation, packages).
- **Electronics:** DC motors/encoders/servos, PWM & H-bridge, basic ADC, safe power (current limits, fusing, LiPo handling).
- **Tools readiness:** Laptop that runs **WSL2 + Ubuntu 24.04**, **VS Code**, Python 3.10+, 30–50 GB free disk; internet access in lab.

## Laboratory learning

Use physical measurements to compare models and algorithms with robot behavior. Simulation supports safe, repeatable, and accessible experiments. The confirmed laboratory resources are:

| Equipment | Quantity | Role |
|---|---:|---|
| Hiwonder ROSOrin Advanced, Jetson Orin | 2 | Mobile kinematics, odometry, perception, SLAM and navigation |
| Hiwonder MentorPi A1 Advanced | 2 | Ackermann motion, vehicle control, path following and navigation |
| Seeed reBot Arm B601-RS | 3 | Manipulator kinematics, Jacobians, control and trajectories |
| Universal Robots UR5e | 1 | Supervised industrial manipulator experiments; independent operation requires training and validation |
| Dynamixel XL330 actuators | 12 | Four planned 3-DOF manipulators; required activities do not depend on their completion |
| Orbbec Gemini 2 RGB-D cameras | 2 | Depth, 3D coordinates and point clouds |
| Standalone RPLIDAR sensors | 4 | LaserScan processing, obstacle detection and mapping |

Use only supported, verified command interfaces and operating limits. Position feedback does not establish that unrestricted torque control is available. Preserve working manufacturer environments; compatibility with the course's Jazzy workspace must be tested before integration.
