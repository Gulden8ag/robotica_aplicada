# ROS 2 Jazzy — Create a Service Client

In this lesson you will create a **service client** in ROS 2 Jazzy using **Python (`rclpy`)**.

We will call the service:

- Interface: `example_interfaces/srv/AddTwoInts`
- Service name: `/add_two_ints`

---


## 1) Client implementation

### Imports

```python
#!/usr/bin/env python3

import rclpy
from rclpy.node import Node

from functools import partial

from example_interfaces.srv import AddTwoInts
```

**What this does**

- `partial` lets us pass extra arguments into a callback cleanly.
- `AddTwoInts` is the service type:
  - `AddTwoInts.Request` has `a`, `b`
  - `AddTwoInts.Response` has `sum`

---

### Define the client node class

```python
class AddTwoIntsClientNode(Node):
    def __init__(self):
        super().__init__("add_two_ints_client")
```

**What this does**
- Creates a node named `add_two_ints_client`

---

### Create the service client

Inside the constructor:

```python
                                            
        self._client = self.create_client(
            AddTwoInts, # service type
            "add_two_ints") # service name (must match server)
```

**Parameters**

- **Type**: `AddTwoInts` which we imported from `example_interfaces.srv`
- **Service name**: `"add_two_ints"` (must match the server) which comes from the server code we wrote in the previous lesson

---

### Method to send requests

Inside the class, add:

```python
    def call_add_two_ints(self, a: int, b: int):
        # Wait for service (safe startup)
        while not self._client.wait_for_service(timeout_sec=1.0):
            self.get_logger().warn("Service '/add_two_ints' not available, waiting...")
        # Build request
        request = AddTwoInts.Request()
        request.a = a
        request.b = b

        # Send async request
        # Creates a Future that will eventually hold the response
        future = self._client.call_async(request)

        # Register callback; pass request too (so we can log a + b)
        # This wont run immediately — it runs when the response arrives
        future.add_done_callback(partial(self.callback_call_add_two_ints, request))
```

**What this does**

1. Wait until the server is available (safe startup)
2. Build a request object, initializing `a` and `b`
3. Send the request asynchronously (`call_async`)
4. Register a callback that will run **when the response arrives**

**Why async?**

- `call()` can block and cause deadlocks in typical ROS node patterns.
- `call_async()` + callbacks works cleanly with `rclpy.spin(node)`.

**Future and callbacks**

- A Future is a placeholder for a result that will arrive later (the response).
- When a response arrives, the callback we registered will be called with the Future, allowing us to extract the response.


---

### Response callback

```python
    # Callback for when the future completes (response received)
    def callback_call_add_two_ints(self, request: AddTwoInts.Request, future):
        response = future.result()
        self.get_logger().info(f"{request.a} + {request.b} = {response.sum}")
```

**What this does**

- Extracts the response from the `future`
- Logs the full equation (we can do this because we passed `request` using `partial`)

---

### Example usage (send multiple requests)

```python
        self.call_add_two_ints(2, 7)
        self.call_add_two_ints(1, 4)
        self.call_add_two_ints(10, 20)
```

**What this demonstrates**

- One client can send **many requests**
- Responses will arrive and trigger the callback each time

---

### `main()` (init → spin → shutdown)

```python
def main(args=None):
    rclpy.init(args=args)
    node = AddTwoIntsClientNode()
    rclpy.spin(node)
    rclpy.shutdown()
```

## 2) Full code 

Create: `my_py_pkg/add_two_ints_client.py`

```python
#!/usr/bin/env python3

import rclpy
from rclpy.node import Node

from functools import partial

from example_interfaces.srv import AddTwoInts


class AddTwoIntsClientNode(Node):
    def __init__(self):
        super().__init__("add_two_ints_client")

        # Create client once
        self._client = self.create_client(AddTwoInts, "add_two_ints")

        # Example calls (send multiple requests)
        self.call_add_two_ints(2, 7)
        self.call_add_two_ints(1, 4)
        self.call_add_two_ints(10, 20)

    def call_add_two_ints(self, a: int, b: int):
        # Wait for service (safe startup)
        while not self._client.wait_for_service(timeout_sec=1.0):
            self.get_logger().warn("Service '/add_two_ints' not available, waiting...")

        # Build request
        request = AddTwoInts.Request()
        request.a = a
        request.b = b

        # Send async request
        future = self._client.call_async(request)

        # Register callback; pass request too (so we can log a + b)
        future.add_done_callback(partial(self.callback_call_add_two_ints, request))

    def callback_call_add_two_ints(self, request: AddTwoInts.Request, future):
        # Extract response
        response = future.result()
        self.get_logger().info(f"{request.a} + {request.b} = {response.sum}")


def main(args=None):
    rclpy.init(args=args)
    node = AddTwoIntsClientNode()
    rclpy.spin(node)
    rclpy.shutdown()


if __name__ == "__main__":
    main()
```

## Change it to ask the user for input

Let's modify the client so it asks the user for two integers in the terminal, then sends the request.

If you want your client to ask the user for numbers in the terminal, you **should not** put a `while rclpy.ok(): input(...)` loop inside `__init__()`.
A loop with `input()` blocks the constructor forever, so your program may never reach:

```python
rclpy.spin(node)
```

Without spinning, ROS 2 may not process incoming service responses, meaning your future done-callback may not run reliably.

Instead, we will use the `threading` module to run a separate thread that handles user input.

First import `threading` at the top:

```python
import threading
```

Then, in the constructor, start a new thread that runs a method to handle user input:

```python
        # Start a separate thread for user input
        threading.Thread(target=self.user_input_loop, daemon=True).start()
```
Finally create the `user_input_loop` method that runs in the separate thread:

```python
def user_input_loop(self):
    while rclpy.ok():
        try:
            a = int(input("Enter first integer (a): "))
            b = int(input("Enter second integer (b): "))
            self.call_add_two_ints(a, b)
        except ValueError:
            print("Please enter valid integers.")
        except (KeyboardInterrupt, EOFError):
            print("Exiting client.")
            break
```
