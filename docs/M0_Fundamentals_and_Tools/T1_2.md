# ROS 2 Jazzy — Create a Service Server

In this lesson you will create a **service server** in ROS 2 Jazzy using **Python (`rclpy`)**.

We will implement a server that receives two integers (`a`, `b`) and returns their sum (`sum`) using the already-installed interface:

- `example_interfaces/srv/AddTwoInts`


## 1) Understand the service interface

Inspect the interface:

```bash
ros2 interface show example_interfaces/srv/AddTwoInts
```

Expected output:

```text
int64 a
int64 b
---
int64 sum
```

The `---` separates:

- **Request** (client → server): `a`, `b`
- **Response** (server → client): `sum`

---

## 2) Server implementation

Below is the same server code, but divided into sections so each part is easier to understand.

---

### Imports

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
# Service interface (srv, not msg)
from example_interfaces.srv import AddTwoInts
```

**What this does**

- Services live under `...srv` (not `...msg`).
- `AddTwoInts` contains both:
    - `AddTwoInts.Request` (fields: `a`, `b`)
    - `AddTwoInts.Response` (field: `sum`)

---

### Define the node class and constructor

```python
class AddTwoIntsServerNode(Node):
    def __init__(self):
        super().__init__("add_two_ints_server")
```

**What this does**

- Creates a node class named `AddTwoIntsServerNode`
- Sets the node name to `add_two_ints_server`

---

### Create the service server

Inside the constructor, we create the service server:

```python
        # Create the service server: (type, service_name, callback)
        self._server = self.create_service(
            AddTwoInts, # service type
            "add_two_ints", # service name
            self.callback_add_two_ints, # callback function
        )

        self.get_logger().info("AddTwoInts service server has been started.")
```

**Parameters explained**

- **Type**: `AddTwoInts` (the service interface)
- **Service name**: `"add_two_ints"`  
  - Recommend using a **verb** for services (actions or computations):  
    `enable_motor`, `compute_ik`, `add_two_ints`
- **Callback**: `self.callback_add_two_ints`  
  - This runs whenever a client calls the service.

---

### The service callback (request → response)

In our node class, we define the callback function that processes incoming service calls:

```python
    def callback_add_two_ints(self, request: AddTwoInts.Request, response: AddTwoInts.Response):
        # Compute result
        response.sum = request.a + request.b

        # Log for visibility
        self.get_logger().info(f"{request.a} + {request.b} = {response.sum}")

        # IMPORTANT: you must return the response in Python
        return response
```

**What this does**

- `request` contains incoming fields: `request.a`, `request.b`
- `response` is the object you must fill: `response.sum = ...`
- **Critical**: In Python service servers, you must **return** `response`  
  If you forget to return it, the node runs but service calls will fail at runtime.

---

### The `main()` function (init → spin → shutdown)

Same as usual, we have a `main()` function to run the node, which initializes ROS, creates the node, spins it, and shuts down cleanly.

```python
def main(args=None):
    rclpy.init(args=args)
    node = AddTwoIntsServerNode()
    rclpy.spin(node)
    rclpy.shutdown()
```

---

## 3) Full code (complete file)

Below is the full server file exactly as you should keep it.

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node

# Service interface (srv, not msg)
from example_interfaces.srv import AddTwoInts


class AddTwoIntsServerNode(Node):
    def __init__(self):
        super().__init__("add_two_ints_server")

        # Create the service server: (type, service_name, callback)
        self._server = self.create_service(
            AddTwoInts,
            "add_two_ints",
            self.callback_add_two_ints,
        )

        self.get_logger().info("AddTwoInts service server has been started.")

    def callback_add_two_ints(self, request: AddTwoInts.Request, response: AddTwoInts.Response):
        # Compute result
        response.sum = request.a + request.b

        # Log for visibility
        self.get_logger().info(f"{request.a} + {request.b} = {response.sum}")

        # IMPORTANT: you must return the response in Python
        return response


def main(args=None):
    rclpy.init(args=args)
    node = AddTwoIntsServerNode()
    rclpy.spin(node)
    rclpy.shutdown()


if __name__ == "__main__":
    main()
```

## 4) Test quickly from terminal

Before testing, make sure you have done the following:

- Added `example_interfaces` as a dependency in your `package.xml`.
- Added an entry point for the server script in your `setup.py`.

With the server running:

```bash
ros2 run my_py_pkg add_two_ints_server
```

Call it:

```bash
ros2 service call /add_two_ints example_interfaces/srv/AddTwoInts "{a: 3, b: 7}"
```
