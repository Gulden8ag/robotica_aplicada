# ROS 2 Jazzy — Custom Service Interface


You will:

1) Create a custom service interface: `ComputeRectangleArea.srv`  
2) Build it in `my_robot_interfaces`  
3) Use it in a **Python service server** based on your **template node**

---

## 1) Create the custom service interface

Inside your interface package:

```bash
cd ~/your_ws/src/my_robot_interfaces
mkdir -p srv
touch srv/ComputeRectangleArea.srv
```

Edit `srv/ComputeRectangleArea.srv`:

```text
float64 length
float64 width
---
float64 area
```

### Register it in `CMakeLists.txt`

Open `my_robot_interfaces/CMakeLists.txt` and add the file path:

```cmake
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/HardwareStatus.msg"
  "srv/ComputeRectangleArea.srv"
)
```

Build and source:

```bash
cd ~/your_ws
colcon build --packages-select my_robot_interfaces
source install/setup.bash
```

Verify:

```bash
ros2 interface show my_robot_interfaces/srv/ComputeRectangleArea
```

---

## 2) Use the service in Python

### 2.1 Add dependency in your Python package

In your Python package `package.xml` (example: `my_py_pkg/package.xml`), add:

```xml
<depend>my_robot_interfaces</depend>
```

---

## 3) Python service server using the template node

We will start from your node template from your first program section.

And we will add:

- the import for the custom service type
- `create_service(...)`
- a callback that computes `area = length * width`

---

### Import the custom service type

```python
from my_robot_interfaces.srv import ComputeRectangleArea
```

---

### Create the service server in `__init__()`

```python
self.server_ = self.create_service(
    ComputeRectangleArea,
    "compute_rectangle_area",
    self.cb_compute_rectangle_area,
)
```

---

### Implement the callback

```python
def cb_compute_rectangle_area(self, request, response):
    response.area = request.length * request.width
    self.get_logger().info(
        f"length={request.length}, width={request.width} -> area={response.area}"
    )
    return response
```

> Reminder: in Python service servers you must **return** the response.

---

## 4) Full server code with the custom service

Create a new file in your Python package, for example:

- `my_py_pkg/compute_rectangle_area_server.py`

```python
#!/usr/bin/env python3

import rclpy
from rclpy.node import Node

from my_robot_interfaces.srv import ComputeRectangleArea


class MyNode(Node):
    def __init__(self):
        super().__init__("compute_rectangle_area_server")

        self.server_ = self.create_service(
            ComputeRectangleArea,
            "compute_rectangle_area",
            self.cb_compute_rectangle_area,
        )

        self.get_logger().info("ComputeRectangleArea service server started.")

    def cb_compute_rectangle_area(self, request, response):
        response.area = request.length * request.width

        self.get_logger().info(
            f"length={request.length}, width={request.width} -> area={response.area}"
        )

        return response


def main(args=None):
    rclpy.init(args=args)
    my_node = MyNode()
    rclpy.spin(my_node)
    rclpy.shutdown()


if __name__ == "__main__":
    main()
```

---

## 5) Register and run

### 5.1 Add to `setup.py`

In your Python package `setup.py`, add a console script entry, like always.

Build it and source:

```bash
cd ~/your_ws
colcon build --packages-select my_py_pkg --symlink-install
source install/setup.bash
```

Run the server:

```bash
ros2 run my_py_pkg compute_rectangle_area_server
```

---

## 6) Test from terminal

Check the service exists:

```bash
ros2 service list
```


Call the service with a request:

```bash
ros2 service call /compute_rectangle_area my_robot_interfaces/srv/ComputeRectangleArea "{length: 3.0, width: 2.5}"
```

Expected response:

- `area: 7.5`
