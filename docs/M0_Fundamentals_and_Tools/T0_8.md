# Install ROS

## 1. Install WSL2 and Ubuntu 24.04

- **If you’re already on native Ubuntu:** Skip this entire **Step 1** (WSL2 and Ubuntu installation).
- **If you’re on Windows 11:** Follow all of these steps.

WSL2 (Windows Subsystem for Linux 2) is an improvement over the original Windows Subsystem for Linux (WSL) that lets you run native Linux distributions on Windows without needing traditional virtual machines.

Open **PowerShell** as administrator:

```bash
wsl --install -d Ubuntu-24.04

```

This command:

- Enables the Windows Subsystem for Linux (WSL) and the Virtual Machine Platform,
- Sets WSL2 as the default version,
- Downloads and installs Ubuntu 24.04 LTS (Noble Numbat is the current stable distro).

## 2. First boot and system update

If you’re on Windows, start Ubuntu (from Start Menu), and create a UNIX user/password (the password will not show characters as you type). Then, in the shell, run:

```bash
sudo apt update
sudo apt full-upgrade -y

```

This will update your Ubuntu system.

## 3. System configuration for ROS 2

Before installing ROS, we need to configure the system so it is compatible.

### 3.1 Set the locale (text encoding)

First, we need to configure the locale, which refers to the system’s language and regional settings. ROS uses **UTF-8**, which helps avoid issues with special characters in ROS and other programs.

```bash
sudo apt update && sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

```

These settings use US English; however, any UTF-8 locale is fine.

```bash
locale # Check that it’s using UTF-8

```

### 3.2 Enable “universe” and add the ROS 2 repository

First, make sure the [Ubuntu Universe](https://docs.ros.org/en/rolling/Releases.html) repository is enabled:

```bash
sudo apt install -y software-properties-common
sudo add-apt-repository universe

```

Now add the ROS 2 GPG key using apt:

```bash
sudo apt update
sudo apt install -y curl
curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  | sudo tee /usr/share/keyrings/ros-archive-keyring.gpg

```

Finally, add the ROS 2 repository to your sources list:

```bash
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  http://packages.ros.org/ros2/ubuntu \
  $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

```

## 4. Install ROS 2 Jazzy Desktop

First update your apt repository to take into account the changes we made:

```bash
sudo apt update
sudo apt upgrade

```

Now perform the full installation:

```bash
sudo apt install ros-jazzy-desktop

```

## 5. Verify the installation with an example

First, we’ll configure the environment. Add automatic sourcing of the ROS commands to your startup file (`~/.bashrc`) so it runs every time you open a terminal:

```bash
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
source ~/.bashrc

```

For this test you’ll need two terminals, so open a second terminal.

In one terminal, run a simple C++ node called `talker`:

```bash
ros2 run demo_nodes_cpp talker

```

In the other terminal, run a Python node called `listener`:

```bash
ros2 run demo_nodes_py listener

```

You should see that `talker` prints to the console **Publishing: numbers**, and in the `listener` console you see **I heard: numbers**, with the messages matching. This verifies that both the C++ and Python APIs are working.

### Install (Dependencies)

```bash
sudo apt update
sudo apt install ros-jazzy-robot-state-publisher ros-jazzy-joint-state-publisher-gui
# (often also handy)
sudo apt install ros-jazzy-xacro ros-jazzy-rviz2 ros-jazzy-tf2-ros

```

Verify with:

```bash
# If these print a path, they’re already installed:
ros2 pkg prefix xacro
ros2 pkg prefix robot_state_publisher
ros2 pkg prefix joint_state_publisher_gui
ros2 pkg prefix rviz2
ros2 pkg prefix tf2_ros

```

## Installation of Gazebo Harmonic

**Official guide: [Gazebo Harmonic – Install on Ubuntu](https://gazebosim.org/docs/harmonic/install_ubuntu/)**

```bash
sudo apt update
sudo apt install gz-harmonic

```

**Warning:** In some cases, the `gz` binary may not be in your PATH until you log out and back in, or run `source /opt/ros/jazzy/setup.bash` again.

**Test:**

```bash
gz sim shapes.sdf

```

A Gazebo window with a test world should open.
