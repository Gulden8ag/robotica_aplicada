# Implementation of Numerical IK Using the Jacobian (Python)

This page shows a practical way to implement **numerical inverse kinematics (IK)** in Python using your existing **DH table** and **forward kinematics (FK)**. It includes three iterative solvers:

- Gauss–Newton (GN)
- Levenberg–Marquardt / Damped Least Squares (LM/DLS)
- Gradient Descent (GD) (baseline / intuition)

> Assumption: You already have your DH parameters (standard DH) and you want to compute FK + Jacobian, then implement numerical IK.

---

## 1. Problem statement (position-only)

We assume:

- FK provides the end-effector position \(p(q)\in\mathbb{R}^3\)
- Desired target position \(p_d\in\mathbb{R}^3\)
- Error: $e(q)=p_d-p(q)$
- Position Jacobian:  $J(q)=\frac{\partial p}{\partial q}\in\mathbb{R}^{3\times n}$

We solve IK by iteratively updating: $q \leftarrow q + \Delta q$


---

## 2. Setup

### 2.1 Choose the task
- **Position-only** (recommended for \(n<6\))
- **Full pose** (position + orientation) (typically requires \(n\ge 6\))

This page focuses on **position-only** IK. Extending to full pose is done by redefining the task variable \(x\) and error \(e\) as 6D.

### 2.2 Objective
$$
q^* = \arg\min_q \|e(q)\|^2
\quad\text{with}\quad
e(q)=p_d-p(q)
$$

### 2.3 Stopping conditions (measurable)
- \(\|e\| < \epsilon\) (e.g., \(1\text{–}5\,\mathrm{mm}\) in simulation)
- Maximum iterations reached
- No improvement for \(N\) iterations (optional)

### 2.4 Safety constraints (always)
- Joint limits: \(q_{\min} \le q \le q_{\max}\)
- Step limit: \(\|\Delta q\| \le \Delta q_{\max}\)

### 4.1 Computing FK from a DH table (Standard DH)

#### 4.1.1 Standard DH transform

For link \(i\), DH parameters are:

- \(a_i\): link length  
- \(\alpha_i\): link twist  
- \(d_i\): link offset  
- \(\theta_i\): joint angle (variable for revolute joints)

Standard DH transform:

$$
{}^{i-1}_iT =
R_z(\theta_i)\,T_z(d_i)\,T_x(a_i)\,R_x(\alpha_i)
$$

Expanded:

$$
{}^{i-1}_iT =
\begin{bmatrix}
\cos\theta_i & -\sin\theta_i\cos\alpha_i & \sin\theta_i\sin\alpha_i & a_i\cos\theta_i\\
\sin\theta_i & \cos\theta_i\cos\alpha_i  & -\cos\theta_i\sin\alpha_i & a_i\sin\theta_i\\
0            & \sin\alpha_i              & \cos\alpha_i              & d_i\\
0 & 0 & 0 & 1
\end{bmatrix}
$$

#### 4.1.2 FK in Python (from a DH table)

Supports:

- Revolute joints: \(\theta_i = \theta_{i,0} + q_i\)
- Prismatic joints: \(d_i = d_{i,0} + q_i\)

```python
import numpy as np

def dh_transform(a, alpha, d, theta):
    ca, sa = np.cos(alpha), np.sin(alpha)
    ct, st = np.cos(theta), np.sin(theta)
    return np.array([
        [ct, -st*ca,  st*sa, a*ct],
        [st,  ct*ca, -ct*sa, a*st],
        [0.0,   sa,     ca,    d],
        [0.0, 0.0,    0.0,   1.0]
    ], dtype=float)

def fk_from_dh(q, dh_table, joint_types):
    # Compute ^0T_n using standard DH.
    #
    # q: (n,) joint variables
    # dh_table: list of dicts with keys: a, alpha, d, theta
    #           where d and theta are the nominal constants (d0, theta0)
    # joint_types: list of 'R' or 'P'
    #   'R' -> theta = theta0 + q[i], d = d0
    #   'P' -> theta = theta0, d = d0 + q[i]

    T = np.eye(4, dtype=float)
    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        a = float(row["a"])
        alpha = float(row["alpha"])
        d0 = float(row["d"])
        th0 = float(row["theta"])

        if jt.upper() == "R":
            theta = th0 + float(q[i])
            d = d0
        elif jt.upper() == "P":
            theta = th0
            d = d0 + float(q[i])
        else:
            raise ValueError("joint_types must contain only 'R' or 'P'.")

        T = T @ dh_transform(a, alpha, d, theta)

    return T

def fk_position_from_dh(q, dh_table, joint_types):
    T = fk_from_dh(q, dh_table, joint_types)
    return T[0:3, 3].copy()
```

### 4.2 Computing the Jacobian analytically (Geometric Jacobian)

Analytic (geometric) Jacobian uses:

- frame origins \(o_i\)
- frame z-axes \(z_i\)
computed from intermediate transforms \({}^0T_i\).

#### 4.2.1 Key formulas

Let:

- \(o_i\): origin of frame \(\{i\}\) expressed in base frame \(\{0\}\)
- \(z_i\): z-axis of frame \(\{i\}\) expressed in \(\{0\}\)
- end-effector origin: \(o_n\)

For joint \(i\) (axis \(z_{i-1}\)):

- Revolute:
  $$
  J_{v,i} = z_{i-1}\times (o_n - o_{i-1}),\qquad
  J_{\omega,i} = z_{i-1}
  $$
- Prismatic:
  $$
  J_{v,i} = z_{i-1},\qquad
  J_{\omega,i} = 0
  $$

For position-only IK:
$$
J_p = \begin{bmatrix}J_{v,1} & \cdots & J_{v,n}\end{bmatrix}\in\mathbb{R}^{3\times n}
$$

#### 4.2.2 Python implementation (position Jacobian)

```python
import numpy as np

def jacobian_position_geometric_from_dh(q, dh_table, joint_types):
    # Compute position Jacobian Jp (3xn) using the geometric Jacobian method.
    n = len(dh_table)

    # Store transforms ^0T_i for i=0..n
    T = np.eye(4, dtype=float)
    Ts = [T.copy()]  # ^0T_0

    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        a = float(row["a"])
        alpha = float(row["alpha"])
        d0 = float(row["d"])
        th0 = float(row["theta"])

        if jt.upper() == "R":
            theta = th0 + float(q[i])
            d = d0
        else:  # 'P'
            theta = th0
            d = d0 + float(q[i])

        T = T @ dh_transform(a, alpha, d, theta)
        Ts.append(T.copy())  # ^0T_{i+1}

    o_n = Ts[-1][0:3, 3].copy()
    Jp = np.zeros((3, n), dtype=float)

    for i in range(n):
        # joint axis is z_{i} from ^0T_i
        T_i = Ts[i]
        z = T_i[0:3, 2].copy()
        o = T_i[0:3, 3].copy()

        if joint_types[i].upper() == "R":
            Jp[:, i] = np.cross(z, (o_n - o))
        else:  # 'P'
            Jp[:, i] = z

    return Jp
```

**Recommendation:** once DH frames are correct, prefer this analytic Jacobian over numeric (faster + more stable).

### 4.3 Computing the Jacobian numerically (Finite Differences)

Numeric Jacobian is useful for debugging FK/Jacobian sign conventions.

$$
J[:,i] \approx \frac{p(q+h\,e_i)-p(q)}{h}
$$

```python
import numpy as np

def jacobian_numeric_position(fk_position, q: np.ndarray, h: float = 1e-4) -> np.ndarray:
    n = q.size
    p0 = fk_position(q)
    J = np.zeros((3, n), dtype=float)
    for i in range(n):
        dq = np.zeros(n, dtype=float)
        dq[i] = h
        p1 = fk_position(q + dq)
        J[:, i] = (p1 - p0) / h
    return J
```

## 5. Numerical IK solvers (position-only)

All solvers below assume you can compute:
- \(p(q)\) (FK)
- \(J_p(q)\) (Jacobian)

> In student projects: start with **LM/DLS** as default. GN is faster when well-conditioned. GD is simplest but slower.

---

### 5.1 Helper utilities (limits + step limiting)

```python
import numpy as np

def clamp(q: np.ndarray, qmin: np.ndarray, qmax: np.ndarray) -> np.ndarray:
    return np.minimum(np.maximum(q, qmin), qmax)

def limit_step(dq: np.ndarray, dq_max: float) -> np.ndarray:
    n = float(np.linalg.norm(dq))
    if n <= dq_max:
        return dq
    return dq * (dq_max / n)
```

### 5.2 Solver 1: Gauss–Newton (GN)

**Update rule**
$$
(J^T J)\,\Delta q = J^T e
\quad\text{with}\quad e=p_d-p(q)
$$

```python
import numpy as np

def ik_gauss_newton(
    fk_position,
    jacobian_position,
    p_des: np.ndarray,
    q0: np.ndarray,
    qmin: np.ndarray,
    qmax: np.ndarray,
    eps: float = 1e-3,
    max_iters: int = 100,
    dq_max: float = np.deg2rad(5.0),
    reg: float = 1e-9,  # tiny regularization to reduce numeric issues
):
    q = clamp(q0.astype(float).copy(), qmin, qmax)

    best_q = q.copy()
    best_err = float("inf")

    for k in range(max_iters):
        p = fk_position(q)
        e = (p_des - p)
        err = float(np.linalg.norm(e))

        if err < best_err:
            best_err = err
            best_q = q.copy()

        if err <= eps:
            return q, True, {"iters": k, "final_error": err}

        J = jacobian_position(q)
        A = J.T @ J + reg * np.eye(q.size)
        b = J.T @ e

        dq = np.linalg.solve(A, b)
        dq = limit_step(dq, dq_max)

        q = clamp(q + dq, qmin, qmax)

    return best_q, False, {"iters": max_iters, "final_error": best_err}
```

### 5.3 Solver 2: Levenberg–Marquardt (LM) / Damped Least Squares (DLS)

**Update rule (LM form)**
$$
(J^T J + \lambda I)\,\Delta q = J^T e
$$

Adaptive damping rule (code-friendly):
- If error decreases: \(\lambda \leftarrow \lambda/2\)
- Else: \(\lambda \leftarrow 2\lambda\) and retry next iteration

```python
import numpy as np

def ik_levenberg_marquardt(
    fk_position,
    jacobian_position,
    p_des: np.ndarray,
    q0: np.ndarray,
    qmin: np.ndarray,
    qmax: np.ndarray,
    eps: float = 1e-3,
    max_iters: int = 200,
    dq_max: float = np.deg2rad(5.0),
    lam0: float = 0.05,
):
    q = clamp(q0.astype(float).copy(), qmin, qmax)
    lam = float(lam0)

    best_q = q.copy()
    best_err = float("inf")

    for k in range(max_iters):
        p = fk_position(q)
        e = (p_des - p)
        err = float(np.linalg.norm(e))

        if err < best_err:
            best_err = err
            best_q = q.copy()

        if err <= eps:
            return q, True, {"iters": k, "final_error": err, "lambda": lam}

        J = jacobian_position(q)
        A = J.T @ J + lam * np.eye(q.size)
        b = J.T @ e

        dq = np.linalg.solve(A, b)
        dq = limit_step(dq, dq_max)

        q_candidate = clamp(q + dq, qmin, qmax)
        err_candidate = float(np.linalg.norm(p_des - fk_position(q_candidate)))

        if err_candidate < err:
            q = q_candidate
            lam = max(lam / 2.0, 1e-6)
        else:
            lam = min(lam * 2.0, 1e3)

    return best_q, False, {"iters": max_iters, "final_error": best_err, "lambda": lam}
```

### 5.4 Solver 3: Gradient Descent (GD) (baseline)

Let \(f(q)=\tfrac12\|e(q)\|^2\). Then:
$$
\nabla f = J^T e
$$
Update:
$$
\Delta q = \alpha J^T e
$$

```python
import numpy as np

def ik_gradient_descent(
    fk_position,
    jacobian_position,
    p_des: np.ndarray,
    q0: np.ndarray,
    qmin: np.ndarray,
    qmax: np.ndarray,
    alpha: float = 0.2,
    eps: float = 1e-3,
    max_iters: int = 200,
    dq_max: float = np.deg2rad(5.0),
):
    q = clamp(q0.astype(float).copy(), qmin, qmax)

    best_q = q.copy()
    best_err = float("inf")

    for k in range(max_iters):
        p = fk_position(q)
        e = (p_des - p)
        err = float(np.linalg.norm(e))

        if err < best_err:
            best_err = err
            best_q = q.copy()

        if err <= eps:
            return q, True, {"iters": k, "final_error": err}

        J = jacobian_position(q)
        dq = alpha * (J.T @ e)
        dq = limit_step(dq, dq_max)

        q = clamp(q + dq, qmin, qmax)

    return best_q, False, {"iters": max_iters, "final_error": best_err}
```

## 6. Example: putting everything together (DH → FK/J → IK)

### 6.1 Define your DH table

Example format:

```python
dh_table = [
    {"a": 0.0,  "alpha": np.pi/2, "d": 0.1, "theta": 0.0},
    {"a": 0.2,  "alpha": 0.0,     "d": 0.0, "theta": 0.0},
    {"a": 0.2,  "alpha": 0.0,     "d": 0.0, "theta": 0.0},
]
joint_types = ["R", "R", "R"]
```

### 6.2 Build FK and Jacobian functions

```python
def fk_position(q):
    return fk_position_from_dh(q, dh_table, joint_types)

def jacobian_position(q):
    return jacobian_position_geometric_from_dh(q, dh_table, joint_types)
```

### 6.3 Solve IK

```python
import numpy as np

# Joint limits example
qmin = np.array([-np.pi, -np.pi/2, -np.pi/2])
qmax = np.array([ np.pi,  np.pi/2,  np.pi/2])

q0 = np.zeros(3)  # seed (use current joints in a real robot)
p_des = np.array([0.25, 0.10, 0.20])  # target [m]

q_sol, ok, info = ik_levenberg_marquardt(fk_position, jacobian_position, p_des, q0, qmin, qmax)
print("Converged:", ok)
print("q_sol:", q_sol)
print("info:", info)

# Verify by FK
p_check = fk_position(q_sol)
print("p_check:", p_check, "error:", np.linalg.norm(p_des - p_check))
```

## 7. Practical notes for student projects

- Start with **position-only** IK (especially for 3-DOF arms).
- Seed with the **current joint state** to ensure smooth motion and avoid branch flips.
- Always log:
  - iterations
  - final error
  - convergence flag
  - damping value (LM)
- If you see instability:
  - increase damping (LM) or reduce step limit
  - verify DH offsets and frame conventions
  - compare analytic Jacobian vs numeric Jacobian to debug

---

## Verification and risks

**Assumptions**
- The target \(p_d\) and FK output \(p(q)\) are expressed in the same base frame.
- Your DH convention (standard vs modified) is consistent with how you built the table.

**Risks + mitigations**
- **Frame mismatch:** verify \(q=0\) pose with URDF/RViz and adjust DH offsets if needed.
- **Unreachable target:** solver returns best error; report it and stop.
- **Singularities:** prefer LM/DLS, enforce step limits.
- **Joint limits:** clamp after every update and reject solutions outside limits.
