#Numerical IK from DH Parameters

The goal is to solve:

$$q \rightarrow p(q)$$

and iteratively find joint values $q$ such that the end-effector position reaches a desired target:

$$p(q) \approx p_d$$

## 1. Problem Statement

We assume we already have:

- A forward kinematics model to compute the current end-effector position $p(q)$
- A desired target position $p_d$An error definition:$e(q) = p_d - p(q)$
- A Jacobian that relates joint motion to end-effector motion:
$\dot{p} = J(q)\dot{q}$

The broad iterative method was presented as:

1. Compute current end-effector pose $p(q)$ via FK
1. Compute error $e(q) = p_d - p(q)$Compute Jacobian $J(q)$
1. Compute update $\Delta q$Limit $\Delta q$ and apply joint limits
1. Update joints $q \leftarrow q + \Delta q$
1. Check stopping conditions and repeat

The current code follows exactly this structure, with one refinement:
Instead of using the simple Jacobian-transpose update:

$$\Delta q = \alpha J^T e$$

It uses a damped least-squares / Levenberg–Marquardt update:

$$\Delta q = (J^T J + \lambda I)^{-1}J^T e$$

Which is usually more stable near singularities and easier to use in practice.


## 2. Step 0 — Build the Forward Kinematics from the DH Table

Before IK can begin, we must be able to compute the robot pose from the joint values.

### 2.1 Standard DH Transform

For each row of the DH table, the code uses the standard Denavit–Hartenberg transform:

$$^{i-1}T_i = R_z(\theta_i)\,T_z(d_i)\,T_x(a_i)\,R_x(\alpha_i)$$

```Python
def dh_transform(a: float, alpha: float, d: float, theta: float) -> np.ndarray:
    """Standard DH transform: Rz(theta) Tz(d) Tx(a) Rx(alpha)."""
    ca, sa = np.cos(alpha), np.sin(alpha)
    ct, st = np.cos(theta), np.sin(theta)

    return np.array([
        [ct, -st * ca,  st * sa, a * ct],
        [st,  ct * ca, -ct * sa, a * st],
        [0.0,      sa,      ca,      d],
        [0.0,     0.0,     0.0,    1.0]
    ], dtype=float)
```

This function creates one homogeneous transform matrix from the DH parameters of one joint.

### 2.2 Full FK from the DH Table

The full end-effector transform is obtained by multiplying all individual transforms:

$$^0T_n = ^0T_1\,^1T_2 \cdots ^{n-1}T_n$$

```Python
def fk_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute ^0T_n using standard DH.

    dh_table rows are dicts with keys: a, alpha, d, theta
    joint_types entries are 'R' or 'P':
      - 'R': theta = theta0 + q[i], d = d0
      - 'P': theta = theta0, d = d0 + q[i]
    """
    if len(dh_table) != len(joint_types) or len(q) != len(joint_types):
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")

    T = np.eye(4, dtype=float)

    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        a = float(row["a"])
        alpha = float(row["alpha"])
        d0 = float(row["d"])
        th0 = float(row["theta"])

        if jt.upper() == "R":
            theta = th0 + float(q[i])
            d = d0
        elif jt.upper() == "P":
            theta = th0
            d = d0 + float(q[i])
        else:
            raise ValueError("joint_types must contain only 'R' or 'P'.")

        T = T @ dh_transform(a, alpha, d, theta)

    return T
```
Interpretation:

- For a revolute joint, the variable is $\theta_i$
- For a prismatic joint, the variable is $d_i$

### 2.3 Extract Only the End-Effector Position

Since this implementation is position-only IK, we only need $p(q)$ from the transform matrix:

$$p(q) = \begin{bmatrix} x(q)\\ y(q)\\ z(q) \end{bmatrix}$$

```Python
def fk_position_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Return end-effector position p(q) from DH FK.
    """
    T = fk_from_dh(q, dh_table, joint_types)
    return T[0:3, 3].copy()
```

This gives the position vector from the last column of the homogeneous transform.

## 3. Step 1 — Compute the Current End-Effector Position

The first step in each IK iteration is determining $p(q)$. 
In the code, this is done here:

```Python
p = fk_position_from_dh(q, dh_table, joint_types)
```

At this point:

- $q$ is the current guess of the joint values
- $p(q)$ is the current end-effector position

## 4. Step 2 — Compute the Position Error

Once the current position is known, compute the difference between desired and current position:

$$e(q) = p_d - p(q)$$

```Python
e = (p_des - p)
err = float(np.linalg.norm(e))
```

Interpretation:

- $e$ is a 3-dimensional vector.
- `err` is the Euclidean norm: 

$\|e\| = \sqrt{e_x^2 + e_y^2 + e_z^2}$. 

This scalar is used to decide whether the solver has converged.

## 5. Step 3 — Compute the Jacobian using the Geometric Method

Your implementation uses the geometric Jacobian, not finite differences and not symbolic differentiation.

The Jacobian maps joint velocity to end-effector linear velocity:

$$\dot{p} = J_p(q)\dot{q}$$

For position-only IK, we only use the linear part of the Jacobian: 

$$J_p \in \mathbb{R}^{3 \times n}$$

### 5.1 Geometric Jacobian Formulas

$$\begin{array}{c|c|c}
& \textbf{Prismatic} & \textbf{Revolute} \\
\hline
\textbf{Linear } (J_{v_i}) & R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix} & R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix} \times (d_n^0 - d_{i-1}^0) \\[18pt]
\hline
\textbf{Rotational } (J_{\omega_i}) & \begin{bmatrix} 0 \\ 0 \\ 0 \end{bmatrix} & R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}
\end{array}$$

For this code, we only use the linear part $J_{v_i}$, because the IK is position-only.

### 5.2 Meaning of Each Term

For each joint $i$:

- $R_{i-1}^0\begin{bmatrix}0\\0\\1\end{bmatrix}$ is the joint axis $z_{i-1}$ expressed in frame 0.
- $d_{i-1}^0$ is the origin of frame $i-1$ expressed in frame 0.
- $d_n^0$ is the end-effector origin expressed in frame 0.

In the code these are extracted as:

- `z = T_i[0:3, 2]`
- `o = T_i[0:3, 3]`
- `o_n = Ts[-1][0:3, 3]`

So the formulas become:

- Revolute joint: $J_{v_i} = z_{i-1} \times (o_n - o_{i-1})$
- Prismatic joint: $J_{v_i} = z_{i-1}$

---

### 5.3 Why the Code Stores Intermediate Transforms

To compute the geometric Jacobian, we need the orientation and origin of every intermediate frame. 

That is why the code stores:

$$^0T_0,\ ^0T_1,\ ^0T_2,\ \dots,\ ^0T_n$$

```Python
T = np.eye(4, dtype=float)
Ts = [T.copy()]  # ^0T_0

for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
    a = float(row["a"])
    alpha = float(row["alpha"])
    d0 = float(row["d"])
    th0 = float(row["theta"])

    if jt.upper() == "R":
        theta = th0 + float(q[i])
        d = d0
    else:  # 'P'
        theta = th0
        d = d0 + float(q[i])

    T = T @ dh_transform(a, alpha, d, theta)
    Ts.append(T.copy())  # ^0T_{i+1}
```
This list `Ts` contains every transform from the base frame to each successive frame.

### 5.4 Jacobian Computation in the Code

```Python
def jacobian_position_geometric_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute position Jacobian Jp (3xn) using the geometric Jacobian method.
    Uses intermediate transforms ^0T_i to extract z_i and o_i.
    """
    n = len(dh_table)
    if len(q) != n or len(joint_types) != n:
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")

    T = np.eye(4, dtype=float)
    Ts = [T.copy()]  # ^0T_0

    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        # ... forward kinematics loop ...
        T = T @ dh_transform(a, alpha, d, theta)
        Ts.append(T.copy())

    o_n = Ts[-1][0:3, 3].copy()
    Jp = np.zeros((3, n), dtype=float)

    for i in range(n):
        T_i = Ts[i]
        z = T_i[0:3, 2].copy()
        o = T_i[0:3, 3].copy()

        if joint_types[i].upper() == "R":
            Jp[:, i] = np.cross(z, (o_n - o))
        else:  # 'P'
            Jp[:, i] = z

    return Jp
```

The code uses:

```python

```

This is exactly:

$$J_{v_i} = z_{i-1} \times (o_n - o_{i-1})$$

which matches the geometric Jacobian formula for revolute joints.

because:

- `z` is $R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}$
- `o` is $d_{i-1}^0$
- `o_n` is $d_n^0$

for a prismatic joint

The code uses:

```python

```

This is exactly:

$$J_{v_i} = z_{i-1}$$

which matches the geometric Jacobian formula for prismatic joints.



## 6. Step 4 — Compute the Joint Update $\triangle q$

In the simple classroom version, the update can be introduced as:

$$\Delta q = \alpha J^T e$$

Where:

- $J^T$ pushes Cartesian error back into joint space
- $\alpha$ is a gain or step size

However, the code uses the Damped Least Squares (DLS) / Levenberg–Marquardt method:

$$\Delta q = (J^T J + \lambda I)^{-1}J^T e$$

```Python
J = jacobian_position_geometric_from_dh(q, dh_table, joint_types)

A = J.T @ J + lam * np.eye(q.size)
b = J.T @ e
dq = np.linalg.solve(A, b)
```

## 7. Step 5 — Limit $\triangle q$ and Apply Joint Limits

Even if the computed step is mathematically correct, it may be too large. Your code applies two protections:

## 7.1 Step Size Limit

```Python
def limit_step(dq: np.ndarray, dq_max: float) -> np.ndarray:
    n = float(np.linalg.norm(dq))
    if n <= dq_max:
        return dq
    return dq * (dq_max / n)
```

If 

$\|\Delta q\| > \Delta q_{\max}$ 

it is scaled down to prevent sudden jumps.

### 7.2 Joint Range Limits

```Python
def clamp(q: np.ndarray, qmin: np.ndarray, qmax: np.ndarray) -> np.ndarray:
    return np.minimum(np.maximum(q, qmin), qmax)
```

This ensures $q_{\min} \le q \le q_{\max}$.

## 8. Step 6 — Update the Joints

The step is:

$$q \leftarrow q + \Delta q$$

In your code, this becomes:

```Python
q_candidate = clamp(q + dq, qmin, qmax)
```

## 9. Step 7 — Check Stopping Conditions and Repeat

The code repeats until the error is small enough or the maximum number of iterations is reached.

### 9.1 Convergence Condition
```Python
if err <= eps:
    return q, True, {"iters": k, "final_error": err, "lambda": lam}
```
Stops when $\|e\| \le \varepsilon$. Where `eps` is the position error tolerance.

### 9.2 Best-So-Far and Adaptive Damping

The code tracks the best solution and changes $\lambda$ depending on whether the new step improved the solution:

```Python
if err < best_err:
    best_err = err
    best_q = q.copy()
```

### 9.3 Adaptive damping

Your solver also changes $\lambda$ depending on whether the new step improved the solution.

```Python
p_candidate = fk_position_from_dh(q_candidate, dh_table, joint_types)
err_candidate = float(np.linalg.norm(p_des - p_candidate))

if err_candidate < err:
    q = q_candidate
    lam = max(lam / 2.0, 1e-6)
else:
    lam = min(lam * 2.0, 1e3)
```


Interpretation

- If the candidate improves the error:

    - accept the step
    - reduce damping

- If the candidate does not improve the error:

    - reject the step
    - increase damping

This makes the method more robust than using a fixed gain.


## 10.  Full solver

```Python
def ik_lm_position_dh(
    p_des: np.ndarray,
    q0: np.ndarray,
    dh_table: list[dict],
    joint_types: list[str],
    qmin: np.ndarray,
    qmax: np.ndarray,
    eps: float = 1e-3,
    max_iters: int = 200,
    dq_max: float = np.deg2rad(5.0),
    lam0: float = 0.05,
) -> tuple[np.ndarray, bool, dict]:
    """
    Levenberg–Marquardt / Damped Least Squares position-only IK.
    Returns (q_sol, converged, info).
    """

    # Initial clamp of the seed
    if p_des.shape != (3,):
        p_des = np.array(p_des, dtype=float).reshape(3)

    q = clamp(q0.astype(float).copy(), qmin, qmax)
    lam = float(lam0)

    best_q = q.copy()
    best_err = float("inf")

    for k in range(max_iters):

        # Step 1: Compute current end-effector position p(q)
        p = fk_position_from_dh(q, dh_table, joint_types)

        # Step 2: Compute error e(q) = p_d - p(q)
        e = (p_des - p)
        err = float(np.linalg.norm(e))

        # Save best result found so far
        if err < best_err:
            best_err = err
            best_q = q.copy()

        # Step 7: Check stopping condition
        if err <= eps:
            return q, True, {"iters": k, "final_error": err, "lambda": lam}

        # Step 3: Compute Jacobian J(q)
        J = jacobian_position_geometric_from_dh(q, dh_table, joint_types)

        # Step 4: Compute update Δq
        # Damped least squares:
        # (J^T J + λI) Δq = J^T e
        A = J.T @ J + lam * np.eye(q.size)
        b = J.T @ e
        dq = np.linalg.solve(A, b)

        # Step 5: Limit Δq
        dq = limit_step(dq, dq_max)

        # Step 6: Update q and apply joint limits
        q_candidate = clamp(q + dq, qmin, qmax)

        # Evaluate candidate
        p_candidate = fk_position_from_dh(q_candidate, dh_table, joint_types)
        err_candidate = float(np.linalg.norm(p_des - p_candidate))

        # Adaptive accept/reject rule
        if err_candidate < err:
            q = q_candidate
            lam = max(lam / 2.0, 1e-6)
        else:
            lam = min(lam * 2.0, 1e3)

    return best_q, False, {"iters": max_iters, "final_error": best_err, "lambda": lam}
```

import numpy as np

# =========================
# 1) DH-BASED FORWARD KINEMATICS
# =========================

def dh_transform(a: float, alpha: float, d: float, theta: float) -> np.ndarray:
    """Standard DH transform: Rz(theta) Tz(d) Tx(a) Rx(alpha)."""
    ca, sa = np.cos(alpha), np.sin(alpha)
    ct, st = np.cos(theta), np.sin(theta)
    return np.array([
        [ct, -st * ca,  st * sa, a * ct],
        [st,  ct * ca, -ct * sa, a * st],
        [0.0,     sa,      ca,      d],
        [0.0,    0.0,     0.0,    1.0]
    ], dtype=float)


def fk_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute ^0T_n using standard DH.

    dh_table rows are dicts with keys: a, alpha, d, theta (d and theta are nominal constants).
    joint_types entries are 'R' or 'P':
      - 'R': theta = theta0 + q[i], d = d0
      - 'P': theta = theta0, d = d0 + q[i]
    """

    # Check input lengths
    if len(dh_table) != len(joint_types) or len(q) != len(joint_types):
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")
    
    T = np.eye(4, dtype=float) # Initialize a transform as identity size 4x4 with float type

    # Loop through each joint and compute the transform
    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        a = float(row["a"]) # Convert the 'a' parameter to a float
        alpha = float(row["alpha"]) # Convert the 'alpha' parameter to a float
        d0 = float(row["d"]) # Convert the 'd' parameter to a float
        th0 = float(row["theta"]) # Convert the 'theta' parameter to a float

        # Check the joint type and compute theta and d accordingly
        if jt.upper() == "R":
            theta = th0 + float(q[i])
            d = d0
        elif jt.upper() == "P":
            theta = th0
            d = d0 + float(q[i])
        else:
            raise ValueError("joint_types must contain only 'R' or 'P'.")

        # Update the overall transform T by multiplying it with the current joint's DH transform
        T = T @ dh_transform(a, alpha, d, theta)

    return T




def fk_position_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Return end-effector position p(q) from DH FK.
    This is a helper that calls fk_from_dh and extracts the position.
    """
    T = fk_from_dh(q, dh_table, joint_types)
    return T[0:3, 3].copy()

    Compute position Jacobian Jp (3xn) using the geometric Jacobian method.
    Uses intermediate transforms ^0T_i to extract z_i and o_i.
    """

    if len(q) != n or len(joint_types) != n:
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")

    # Store transforms ^0T_i for i=0..n
    T = np.eye(4, dtype=float)
    Ts = [T.copy()]  # ^0T_0

    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        a = float(row["a"])
        alpha = float(row["alpha"])
        d0 = float(row["d"])
        th0 = float(row["theta"])

        if jt.upper() == "R":

            d = d0
        else:  # 'P'
            theta = th0
            d = d0 + float(q[i])

        T = T @ dh_transform(a, alpha, d, theta)

def clamp(q: np.ndarray, qmin: np.ndarray, qmax: np.ndarray) -> np.ndarray:
    return np.minimum(np.maximum(q, qmin), qmax)


def limit_step(dq: np.ndarray, dq_max: float) -> np.ndarray:
    n = float(np.linalg.norm(dq))
    if n <= dq_max:
        return dq
    return dq * (dq_max / n)


def ik_lm_position_dh(
    p_des: np.ndarray,
    q0: np.ndarray,
    dh_table: list[dict],
    joint_types: list[str],
    qmin: np.ndarray,
    qmax: np.ndarray,
    eps: float = 1e-3,                 # meters (1e-3 = 1 mm)
    max_iters: int = 200,
    dq_max: float = np.deg2rad(5.0),   # max joint step per iter
    lam0: float = 0.05,
) -> tuple[np.ndarray, bool, dict]:
    """
    Levenberg–Marquardt / Damped Least Squares position-only IK.
    Returns (q_sol, converged, info).
    """
    if p_des.shape != (3,):
        p_des = np.array(p_des, dtype=float).reshape(3)

    q = clamp(q0.astype(float).copy(), qmin, qmax)
    lam = float(lam0)

    best_q = q.copy()
    best_err = float("inf")

    for k in range(max_iters):
        p = fk_position_from_dh(q, dh_table, joint_types)
        e = (p_des - p)
        err = float(np.linalg.norm(e))

        if err < best_err:
            best_err = err
            best_q = q.copy()

        if err <= eps:
            return q, True, {"iters": k, "final_error": err, "lambda": lam}

        J = jacobian_position_geometric_from_dh(q, dh_table, joint_types)

        # LM: (J^T J + lam I) dq = J^T e
        A = J.T @ J + lam * np.eye(q.size)
        b = J.T @ e

        dq = np.linalg.solve(A, b)
        dq = limit_step(dq, dq_max)

        q_candidate = clamp(q + dq, qmin, qmax)
        p_candidate = fk_position_from_dh(q_candidate, dh_table, joint_types)
        err_candidate = float(np.linalg.norm(p_des - p_candidate))

        # accept/reject step with adaptive damping
        if err_candidate < err:
            q = q_candidate
            lam = max(lam / 2.0, 1e-6)
        else:
            lam = min(lam * 2.0, 1e3)

    return best_q, False, {"iters": max_iters, "final_error": best_err, "lambda": lam}
