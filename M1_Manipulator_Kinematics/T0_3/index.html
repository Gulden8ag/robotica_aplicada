    Numerical IK from DH Parameters

    The goal is to solve:

    \[q \rightarrow p(q)\]

    and iteratively find joint values \(q\) such that the end-effector position reaches a desired target:

    \[p(q) \approx p_d\]

    1. Problem Statement

    We assume we already have:

    • A forward kinematics model to compute the current end-effector position \(p(q)\)
    • A desired target position \(p_d\)An error definition:\(e(q) = p_d - p(q)\)
    • A Jacobian that relates joint motion to end-effector motion: \(\dot{p} = J(q)\dot{q}\)

    The broad iterative method was presented as:

    1. Compute current end-effector pose \(p(q)\) via FK
    2. Compute error \(e(q) = p_d - p(q)\)Compute Jacobian \(J(q)\)
    3. Compute update \(\Delta q\)Limit \(\Delta q\) and apply joint limits
    4. Update joints \(q \leftarrow q + \Delta q\)
    5. Check stopping conditions and repeat

    The current code follows exactly this structure, with one refinement: Instead of using the simple Jacobian-transpose update:

    \[\Delta q = \alpha J^T e\]

    It uses a damped least-squares / Levenberg–Marquardt update:

    \[\Delta q = (J^T J + \lambda I)^{-1}J^T e\]

    Which is usually more stable near singularities and easier to use in practice.

    2. Step 0 — Build the Forward Kinematics from the DH Table

    Before IK can begin, we must be able to compute the robot pose from the joint values.

    2.1 Standard DH Transform

    For each row of the DH table, the code uses the standard Denavit–Hartenberg transform:

    \[^{i-1}T_i = R_z(\theta_i)\,T_z(d_i)\,T_x(a_i)\,R_x(\alpha_i)\]
    def dh_transform(a: float, alpha: float, d: float, theta: float) -> np.ndarray:
    """Standard DH transform: Rz(theta) Tz(d) Tx(a) Rx(alpha)."""
    ca, sa = np.cos(alpha), np.sin(alpha)
    ct, st = np.cos(theta), np.sin(theta)

    return np.array([
        [ct, -st * ca,  st * sa, a * ct],
        [st,  ct * ca, -ct * sa, a * st],
        [0.0,      sa,      ca,      d],
        [0.0,     0.0,     0.0,    1.0]
    ], dtype=float)

    This function creates one homogeneous transform matrix from the DH parameters of one joint.

    2.2 Full FK from the DH Table

    The full end-effector transform is obtained by multiplying all individual transforms:

    \[^0T_n = ^0T_1\,^1T_2 \cdots ^{n-1}T_n\]

    def fk_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute ^0T_n using standard DH.

    dh_table rows are dicts with keys: a, alpha, d, theta
    joint_types entries are 'R' or 'P':
      - 'R': theta = theta0 + q[i], d = d0
      - 'P': theta = theta0, d = d0 + q[i]
    """
    if len(dh_table) != len(joint_types) or len(q) != len(joint_types):
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")

    T = np.eye(4, dtype=float)

    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        a = float(row["a"])
        alpha = float(row["alpha"])
        d0 = float(row["d"])
        th0 = float(row["theta"])

        if jt.upper() == "R":
            theta = th0 + float(q[i])
            d = d0
        elif jt.upper() == "P":
            theta = th0
            d = d0 + float(q[i])
        else:
            raise ValueError("joint_types must contain only 'R' or 'P'.")

        T = T @ dh_transform(a, alpha, d, theta)

    return T
    Interpretation:

    • For a revolute joint, the variable is \(\theta_i\)
    • For a prismatic joint, the variable is \(d_i\)

    2.3 Extract Only the End-Effector Position

    Since this implementation is position-only IK, we only need \(p(q)\) from the transform matrix:

    \[p(q) = \begin{bmatrix} x(q)\\ y(q)\\ z(q) \end{bmatrix}\]
    def fk_position_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Return end-effector position p(q) from DH FK.
    """
    T = fk_from_dh(q, dh_table, joint_types)
    return T[0:3, 3].copy()

    This gives the position vector from the last column of the homogeneous transform.

    3. Step 1 — Compute the Current End-Effector Position

    The first step in each IK iteration is determining \(p(q)\). In the code, this is done here:

    p = fk_position_from_dh(q, dh_table, joint_types)

    At this point:

    • \(q\) is the current guess of the joint values
    • \(p(q)\) is the current end-effector position

    4. Step 2 — Compute the Position Error

    Once the current position is known, compute the difference between desired and current position:

    \[e(q) = p_d - p(q)\]
    e = (p_des - p)
err = float(np.linalg.norm(e))

    Interpretation:

    • \(e\) is a 3-dimensional vector.
    • err is the Euclidean norm:

    \(\|e\| = \sqrt{e_x^2 + e_y^2 + e_z^2}\).

    This scalar is used to decide whether the solver has converged.

    5. Step 3 — Compute the Jacobian using the Geometric Method

    Your implementation uses the geometric Jacobian, not finite differences and not symbolic differentiation.

    The Jacobian maps joint velocity to end-effector linear velocity:

    \[\dot{p} = J_p(q)\dot{q}\]

    For position-only IK, we only use the linear part of the Jacobian:

    \[J_p \in \mathbb{R}^{3 \times n}\]

    5.1 Geometric Jacobian Formulas

    \[\begin{array}{c|c|c} & \textbf{Prismatic} & \textbf{Revolute} \\ \hline \textbf{Linear } (J_{v_i}) & R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix} & R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix} \times (d_n^0 - d_{i-1}^0) \\[18pt] \hline \textbf{Rotational } (J_{\omega_i}) & \begin{bmatrix} 0 \\ 0 \\ 0 \end{bmatrix} & R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix} \end{array}\]

    For this code, we only use the linear part \(J_{v_i}\), because the IK is position-only.

    5.2 Meaning of Each Term

    For each joint \(i\):

    • \(R_{i-1}^0\begin{bmatrix}0\\0\\1\end{bmatrix}\) is the joint axis \(z_{i-1}\) expressed in frame 0.
    • \(d_{i-1}^0\) is the origin of frame \(i-1\) expressed in frame 0.
    • \(d_n^0\) is the end-effector origin expressed in frame 0.

    In the code these are extracted as:

    • z = T_i[0:3, 2]
    • o = T_i[0:3, 3]
    • o_n = Ts[-1][0:3, 3]

    So the formulas become:

    • Revolute joint: \(J_{v_i} = z_{i-1} \times (o_n - o_{i-1})\)
    • Prismatic joint: \(J_{v_i} = z_{i-1}\)

    5.3 Why the Code Stores Intermediate Transforms

    To compute the geometric Jacobian, we need the orientation and origin of every intermediate frame.

    That is why the code stores:

    \[^0T_0,\ ^0T_1,\ ^0T_2,\ \dots,\ ^0T_n\]

    T = np.eye(4, dtype=float)
Ts = [T.copy()]  # ^0T_0

for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
    a = float(row["a"])
    alpha = float(row["alpha"])
    d0 = float(row["d"])
    th0 = float(row["theta"])

    if jt.upper() == "R":
        theta = th0 + float(q[i])
        d = d0
    else:  # 'P'
        theta = th0
        d = d0 + float(q[i])

    T = T @ dh_transform(a, alpha, d, theta)
    Ts.append(T.copy())  # ^0T_{i+1}
    This list Ts contains every transform from the base frame to each successive frame.

    5.4 Jacobian Computation in the Code

    def jacobian_position_geometric_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute position Jacobian Jp (3xn) using the geometric Jacobian method.
    Uses intermediate transforms ^0T_i to extract z_i and o_i.
    """
    n = len(dh_table)
    if len(q) != n or len(joint_types) != n:
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")

    T = np.eye(4, dtype=float)
    Ts = [T.copy()]  # ^0T_0

    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        # ... forward kinematics loop ...
        T = T @ dh_transform(a, alpha, d, theta)
        Ts.append(T.copy())

    o_n = Ts[-1][0:3, 3].copy()
    Jp = np.zeros((3, n), dtype=float)

    for i in range(n):
        T_i = Ts[i]
        z = T_i[0:3, 2].copy()
        o = T_i[0:3, 3].copy()

        if joint_types[i].upper() == "R":
            Jp[:, i] = np.cross(z, (o_n - o))
        else:  # 'P'
            Jp[:, i] = z

    return Jp

    5.5 Mapping the code to the geometric table

    For a revolute joint

    The code uses:

    Jp[:, i] = np.cross(z, (o_n - o))

    This is exactly:

    \[J_{v_i} = z_{i-1} \times (o_n - o_{i-1})\]

    which matches the geometric Jacobian formula for revolute joints.

    because:

    • z is \(R_{i-1}^0 \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}\)
    • o is \(d_{i-1}^0\)
    • o_n is \(d_n^0\)

    for a prismatic joint

    The code uses:

    Jp[:, i] = z

    This is exactly:

    \[J_{v_i} = z_{i-1}\]

    which matches the geometric Jacobian formula for prismatic joints.

    6. Step 4 — Compute the Joint Update \(\triangle q\)

    In the simple classroom version, the update can be introduced as:

    \[\Delta q = \alpha J^T e\]

    Where:

    • \(J^T\) pushes Cartesian error back into joint space
    • \(\alpha\) is a gain or step size

    However, the code uses the Damped Least Squares (DLS) / Levenberg–Marquardt method:

    \[\Delta q = (J^T J + \lambda I)^{-1}J^T e\]
    J = jacobian_position_geometric_from_dh(q, dh_table, joint_types)

A = J.T @ J + lam * np.eye(q.size)
b = J.T @ e
dq = np.linalg.solve(A, b)

    7. Step 5 — Limit \(\triangle q\) and Apply Joint Limits

    Even if the computed step is mathematically correct, it may be too large. Your code applies two protections:

    7.1 Step Size Limit

    def limit_step(dq: np.ndarray, dq_max: float) -> np.ndarray:
    n = float(np.linalg.norm(dq))
    if n <= dq_max:
        return dq
    return dq * (dq_max / n)

    If

    \(\|\Delta q\| > \Delta q_{\max}\)

    it is scaled down to prevent sudden jumps.

    7.2 Joint Range Limits

    def clamp(q: np.ndarray, qmin: np.ndarray, qmax: np.ndarray) -> np.ndarray:
    return np.minimum(np.maximum(q, qmin), qmax)

    This ensures \(q_{\min} \le q \le q_{\max}\).

    8. Step 6 — Update the Joints

    The step is:

    \[q \leftarrow q + \Delta q\]

    In your code, this becomes:

    q_candidate = clamp(q + dq, qmin, qmax)

    9. Step 7 — Check Stopping Conditions and Repeat

    The code repeats until the error is small enough or the maximum number of iterations is reached.

    9.1 Convergence Condition

    if err <= eps:
    return q, True, {"iters": k, "final_error": err, "lambda": lam}
    Stops when \(\|e\| \le \varepsilon\). Where eps is the position error tolerance.

    9.2 Best-So-Far and Adaptive Damping

    The code tracks the best solution and changes \(\lambda\) depending on whether the new step improved the solution:

    if err < best_err:
    best_err = err
    best_q = q.copy()

    9.3 Adaptive damping

    Your solver also changes \(\lambda\) depending on whether the new step improved the solution.

    p_candidate = fk_position_from_dh(q_candidate, dh_table, joint_types)
err_candidate = float(np.linalg.norm(p_des - p_candidate))

if err_candidate < err:
    q = q_candidate
    lam = max(lam / 2.0, 1e-6)
else:
    lam = min(lam * 2.0, 1e3)

    Interpretation

    • If the candidate improves the error:

      • accept the step
      • reduce damping

    • If the candidate does not improve the error:

      • reject the step
      • increase damping

    This makes the method more robust than using a fixed gain.

    10. Full solver

    def ik_lm_position_dh(
    p_des: np.ndarray,
    q0: np.ndarray,
    dh_table: list[dict],
    joint_types: list[str],
    qmin: np.ndarray,
    qmax: np.ndarray,
    eps: float = 1e-3,
    max_iters: int = 200,
    dq_max: float = np.deg2rad(5.0),
    lam0: float = 0.05,
) -> tuple[np.ndarray, bool, dict]:
    """
    Levenberg–Marquardt / Damped Least Squares position-only IK.
    Returns (q_sol, converged, info).
    """

    # Initial clamp of the seed
    if p_des.shape != (3,):
        p_des = np.array(p_des, dtype=float).reshape(3)

    q = clamp(q0.astype(float).copy(), qmin, qmax)
    lam = float(lam0)

    best_q = q.copy()
    best_err = float("inf")

    for k in range(max_iters):

        # Step 1: Compute current end-effector position p(q)
        p = fk_position_from_dh(q, dh_table, joint_types)

        # Step 2: Compute error e(q) = p_d - p(q)
        e = (p_des - p)
        err = float(np.linalg.norm(e))

        # Save best result found so far
        if err < best_err:
            best_err = err
            best_q = q.copy()

        # Step 7: Check stopping condition
        if err <= eps:
            return q, True, {"iters": k, "final_error": err, "lambda": lam}

        # Step 3: Compute Jacobian J(q)
        J = jacobian_position_geometric_from_dh(q, dh_table, joint_types)

        # Step 4: Compute update Δq
        # Damped least squares:
        # (J^T J + λI) Δq = J^T e
        A = J.T @ J + lam * np.eye(q.size)
        b = J.T @ e
        dq = np.linalg.solve(A, b)

        # Step 5: Limit Δq
        dq = limit_step(dq, dq_max)

        # Step 6: Update q and apply joint limits
        q_candidate = clamp(q + dq, qmin, qmax)

        # Evaluate candidate
        p_candidate = fk_position_from_dh(q_candidate, dh_table, joint_types)
        err_candidate = float(np.linalg.norm(p_des - p_candidate))

        # Adaptive accept/reject rule
        if err_candidate < err:
            q = q_candidate
            lam = max(lam / 2.0, 1e-6)
        else:
            lam = min(lam * 2.0, 1e3)

    return best_q, False, {"iters": max_iters, "final_error": best_err, "lambda": lam}

    12. Full example code of application

    import numpy as np

# =========================
# 1) DH-BASED FORWARD KINEMATICS
# =========================

def dh_transform(a: float, alpha: float, d: float, theta: float) -> np.ndarray:
    """
    Build one standard Denavit-Hartenberg homogeneous transform.

    Standard DH order:
        Rz(theta) -> Tz(d) -> Tx(a) -> Rx(alpha)

    Parameters
    ----------
    a : float
        Link length along x_{i-1}.
    alpha : float
        Link twist from z_{i-1} to z_i, measured about x_{i-1}.
    d : float
        Link offset along z_{i-1}.
    theta : float
        Joint angle about z_{i-1}.

    Returns
    -------
    np.ndarray
        4x4 homogeneous transform matrix ^{i-1}T_i.
    """
    # Precompute trigonometric terms to make the matrix expression cleaner
    ca, sa = np.cos(alpha), np.sin(alpha)
    ct, st = np.cos(theta), np.sin(theta)

    # Standard DH homogeneous transform
    return np.array([
        [ct, -st * ca,  st * sa, a * ct],
        [st,  ct * ca, -ct * sa, a * st],
        [0.0,      sa,      ca,      d],
        [0.0,     0.0,     0.0,    1.0]
    ], dtype=float)


def fk_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute the full forward kinematics ^0T_n from a standard DH table.

    Each row in dh_table must contain:
        {"a": ..., "alpha": ..., "d": ..., "theta": ...}

    Joint types:
        'R' -> revolute joint
            theta = theta0 + q[i]
            d = d0
        'P' -> prismatic joint
            theta = theta0
            d = d0 + q[i]

    Parameters
    ----------
    q : np.ndarray
        Joint variable vector of length n.
    dh_table : list[dict]
        DH parameter table with one dictionary per joint.
    joint_types : list[str]
        Joint type list with entries 'R' or 'P'.

    Returns
    -------
    np.ndarray
        4x4 homogeneous transform from base frame to end-effector frame, ^0T_n.
    """

    # Validate that the robot description and the joint vector all have the same length
    if len(dh_table) != len(joint_types) or len(q) != len(joint_types):
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")

    # Start with identity because multiplying by identity leaves the first transform unchanged
    T = np.eye(4, dtype=float)

    # Multiply the transform of each joint/link one by one
    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        # Read the nominal DH constants for this joint
        a = float(row["a"])
        alpha = float(row["alpha"])
        d0 = float(row["d"])
        th0 = float(row["theta"])

        # Convert the nominal DH row into the actual DH row using the current joint value q[i]
        if jt.upper() == "R":
            # Revolute joint: theta changes, d stays fixed
            theta = th0 + float(q[i])
            d = d0
        elif jt.upper() == "P":
            # Prismatic joint: d changes, theta stays fixed
            theta = th0
            d = d0 + float(q[i])
        else:
            raise ValueError("joint_types must contain only 'R' or 'P'.")

        # Accumulate the transform:
        # ^0T_i = ^0T_{i-1} * ^{i-1}T_i
        T = T @ dh_transform(a, alpha, d, theta)

    return T


def fk_position_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute only the end-effector position p(q) from the DH-based FK.

    This is a convenience function that calls fk_from_dh(...) and then
    extracts the translation vector from the last column of the 4x4 matrix.

    Returns
    -------
    np.ndarray
        3x1 position vector [x, y, z].
    """
    T = fk_from_dh(q, dh_table, joint_types)

    # In a homogeneous transform, the last column stores the position
    return T[0:3, 3].copy()


# =========================
# 2) GEOMETRIC POSITION JACOBIAN
# =========================

def jacobian_position_geometric_from_dh(q: np.ndarray, dh_table: list[dict], joint_types: list[str]) -> np.ndarray:
    """
    Compute the geometric position Jacobian Jp (3xn).

    This function builds all intermediate transforms ^0T_i so that it can extract:
        - o_i : origin of frame i expressed in frame 0
        - z_i : z-axis of frame i expressed in frame 0

    For each joint i:
        Revolute:
            Jp[:, i] = z_{i-1} x (o_n - o_{i-1})
        Prismatic:
            Jp[:, i] = z_{i-1}

    Parameters
    ----------
    q : np.ndarray
        Joint vector.
    dh_table : list[dict]
        DH table.
    joint_types : list[str]
        Joint type list ('R' or 'P').

    Returns
    -------
    np.ndarray
        3xn position Jacobian.
    """
    n = len(dh_table)

    # Validate dimensions
    if len(q) != n or len(joint_types) != n:
        raise ValueError("Lengths of q, dh_table, and joint_types must match.")

    # Ts will store:
    # Ts[0] = ^0T_0
    # Ts[1] = ^0T_1
    # ...
    # Ts[n] = ^0T_n
    T = np.eye(4, dtype=float)
    Ts = [T.copy()]

    # Build all intermediate transforms from base to each frame
    for i, (row, jt) in enumerate(zip(dh_table, joint_types)):
        a = float(row["a"])
        alpha = float(row["alpha"])
        d0 = float(row["d"])
        th0 = float(row["theta"])

        # Apply the correct joint variable depending on the joint type
        if jt.upper() == "R":
            theta = th0 + float(q[i])
            d = d0
        else:  # 'P'
            theta = th0
            d = d0 + float(q[i])

        # Update cumulative transform and store it
        T = T @ dh_transform(a, alpha, d, theta)
        Ts.append(T.copy())

    # End-effector origin o_n expressed in the base frame
    o_n = Ts[-1][0:3, 3].copy()

    # Initialize the Jacobian matrix
    Jp = np.zeros((3, n), dtype=float)

    # Build one column per joint
    for i in range(n):
        # For joint i, the joint axis is z_{i} in Python indexing,
        # which corresponds to z_{i-1} in the usual 1-based robotics notation
        T_i = Ts[i]

        # z-axis of the current joint frame expressed in the base frame
        z = T_i[0:3, 2].copy()

        # origin of the current joint frame expressed in the base frame
        o = T_i[0:3, 3].copy()

        if joint_types[i].upper() == "R":
            # Revolute joint contribution to end-effector linear velocity
            # Jv_i = z x (o_n - o)
            Jp[:, i] = np.cross(z, (o_n - o))
        else:  # 'P'
            # Prismatic joint contribution to end-effector linear velocity
            # Jv_i = z
            Jp[:, i] = z

    return Jp

# 3) NUMERICAL IK (LM / DLS) FOR POSITION-ONLY

def clamp(q: np.ndarray, qmin: np.ndarray, qmax: np.ndarray) -> np.ndarray:
    """
    Clamp each joint value between its minimum and maximum limit.

    Parameters
    ----------
    q : np.ndarray
        Joint vector to clamp.
    qmin : np.ndarray
        Minimum joint limits.
    qmax : np.ndarray
        Maximum joint limits.

    Returns
    -------
    np.ndarray
        Clamped joint vector.
    """
    return np.minimum(np.maximum(q, qmin), qmax)


def limit_step(dq: np.ndarray, dq_max: float) -> np.ndarray:
    """
    Limit the magnitude of the joint update vector.

    If ||dq|| <= dq_max, return dq unchanged.
    Otherwise, scale dq so that its norm becomes exactly dq_max.

    This prevents overly large jumps that can destabilize IK.

    Parameters
    ----------
    dq : np.ndarray
        Proposed joint update.
    dq_max : float
        Maximum allowed norm of the update.

    Returns
    -------
    np.ndarray
        Possibly scaled update vector.
    """
    n = float(np.linalg.norm(dq))
    if n <= dq_max:
        return dq
    return dq * (dq_max / n)


def ik_lm_position_dh(
    p_des: np.ndarray,
    q0: np.ndarray,
    dh_table: list[dict],
    joint_types: list[str],
    qmin: np.ndarray,
    qmax: np.ndarray,
    eps: float = 1e-3,                 # Convergence tolerance in meters
    max_iters: int = 200,              # Maximum number of IK iterations
    dq_max: float = np.deg2rad(5.0),   # Maximum joint-step norm per iteration
    lam0: float = 0.05,                # Initial damping value
) -> tuple[np.ndarray, bool, dict]:
    """
    Solve position-only inverse kinematics using
    Levenberg-Marquardt / Damped Least Squares.

    The method iterates:
        1. Compute current position p(q)
        2. Compute Cartesian error e = p_des - p(q)
        3. Compute Jacobian J(q)
        4. Solve:
               (J^T J + lambda I) dq = J^T e
        5. Limit the step
        6. Apply joint limits
        7. Accept or reject the step using adaptive damping

    Parameters
    ----------
    p_des : np.ndarray
        Desired end-effector position, shape (3,).
    q0 : np.ndarray
        Initial joint guess.
    dh_table : list[dict]
        DH table.
    joint_types : list[str]
        Joint type list.
    qmin : np.ndarray
        Lower joint limits.
    qmax : np.ndarray
        Upper joint limits.
    eps : float
        Position error tolerance for convergence.
    max_iters : int
        Maximum number of iterations.
    dq_max : float
        Maximum norm of the step per iteration.
    lam0 : float
        Initial damping factor.

    Returns
    -------
    tuple[np.ndarray, bool, dict]
        q_sol : np.ndarray
            Best or converged joint solution.
        converged : bool
            True if the solver met the tolerance.
        info : dict
            Extra information such as iteration count and final error.
    """
    # Ensure the target position is a 3-element vector
    if p_des.shape != (3,):
        p_des = np.array(p_des, dtype=float).reshape(3)

    # Start from the initial guess, but clamp it to respect joint limits
    q = clamp(q0.astype(float).copy(), qmin, qmax)

    # Current damping factor
    lam = float(lam0)

    # Keep track of the best solution found, even if convergence is not reached
    best_q = q.copy()
    best_err = float("inf")

    for k in range(max_iters):
        # Step 1: Compute the current end-effector position with FK
        p = fk_position_from_dh(q, dh_table, joint_types)

        # Step 2: Compute Cartesian position error
        e = (p_des - p)
        err = float(np.linalg.norm(e))

        # Save best-so-far solution
        if err < best_err:
            best_err = err
            best_q = q.copy()

        # Step 7: Stop if the error is already below tolerance
        if err <= eps:
            return q, True, {"iters": k, "final_error": err, "lambda": lam}

        # Step 3: Compute the position Jacobian
        J = jacobian_position_geometric_from_dh(q, dh_table, joint_types)

        # Step 4: Compute the LM / DLS joint update
        #
        # Solve:
        #     (J^T J + lambda I) dq = J^T e
        #
        # The damping term lambda I improves numerical robustness,
        # especially near singularities.
        A = J.T @ J + lam * np.eye(q.size)
        b = J.T @ e
        dq = np.linalg.solve(A, b)

        # Step 5: Limit the update magnitude
        dq = limit_step(dq, dq_max)

        # Step 6: Apply the update and then clamp the candidate to joint limits
        q_candidate = clamp(q + dq, qmin, qmax)

        # Evaluate whether the candidate actually improved the Cartesian error
        p_candidate = fk_position_from_dh(q_candidate, dh_table, joint_types)
        err_candidate = float(np.linalg.norm(p_des - p_candidate))

        # Accept or reject the candidate using adaptive damping
        if err_candidate < err:
            # Improvement found: accept the step
            q = q_candidate

            # Reduce damping so the method behaves more like least-squares
            lam = max(lam / 2.0, 1e-6)
        else:
            # No improvement: reject the step and increase damping
            # so the next step becomes more conservative
            lam = min(lam * 2.0, 1e3)

    # If the loop ends without convergence, return the best solution found
    return best_q, False, {"iters": max_iters, "final_error": best_err, "lambda": lam}
